# 训练证据模型核验的订阅授权

在[最小分享预览](learning-model-review.md)之后，提供持久化草稿、精确同意、取消和历史查询。新增 `0038_learning_model_authorizations.sql`。本阶段不派发模型、不保存模型建议，也不写入自评或 API 金额账本。页面明确显示“已保存授权，尚未执行”；授权不能证明订阅额度充足或模型可用。

## 绑定和期限

草稿从当前用户的有效证据构造，绑定计划、任务、证据输入摘要、订阅连接 ID/版本、登记模型、请求 ID、创建和到期时间。仅接受该用户 active、未过期且登记了所选模型的连接；令牌、账户 subject、client ID 等本地凭据不进入分享或响应。授权摘要使用独立版本 `learning-subscription-consent-v1`，包括所有上述绑定，用户不能提交替代正文、报价或“我是 Pro”的自报授权。

有效期最多五分钟，并受连接到期时间约束。每用户 UTC 日最多创建 20 份，累计最多 1000 份；取消或到期不返还创建次数。同一个请求 ID、任务、连接版本和模型重试返回原记录，即使已取消或失效也不会重建或续期；改变任一字段冲突。

数据库只保存绑定和同意元数据，不复制证据或分享正文。读取 draft/authorized 时，在用户锁内从原始记录重建分享并校验摘要；来源不存在或版本变化时变为 invalidated，preview 为空。只要内容未变化，重建得到的分享与授权摘要保持一致。后续执行器必须在同一互斥边界内重新核对并一次领取，不能把读接口当作领取。

## 状态和事务

状态：draft → authorized；两者均可进入 cancelled/expired/invalidated，终态不可再次批准。批准须精确匹配摘要，同时显式确认分享内容和消耗订阅额度，不接受金额同意替代。重复批准保留首次批准时间。创建、批准、取消和审计写入共用事务，使用现有用户行锁，与学习更新及连接撤销串行；失败全部回滚。

审计仅记录状态和时间，不含证据或凭据。证据更新/删除、所属计划更新/删除、连接更新/撤销/删除立即作废相应活动授权；技能更新/删除、自评更新/撤销保守作废该用户的全部活动授权。创建新的独立自评不触发作废，读接口仍检查计划来源。到期在读取、列表或操作中持久化；拒绝批准过期/失效记录时仍提交失效维护，不保存同意。删除账户级联清理授权和审计。这里没有删除后续训练或其他独立材料。

## HTTP

全部要求会话并返回 no-store；POST 另外要求 CSRF 请求头，严格拒绝未知字段；请求体沿用 16 KiB 上限。

- `POST /api/learning/plans/{plan}/tasks/{task}/evidence/model-authorizations`：request_id、connection_id、十进制字符串 connection_revision、model。
- `GET /api/learning/model-authorizations?after=…`：UUID 升序、每页 20 份；next_cursor 表示还有下一页。
- `GET /api/learning/model-authorizations/{request}`：当前状态和仍有效的完整分享预览。
- `POST …/{request}/approve`：digest、acknowledge_sharing、acknowledge_subscription_usage。
- `POST …/{request}/cancel`：空对象，重复取消幂等。

路径和请求 UUID 在 HTTP/仓储两层校验；Next 代理只放行精确路径及方法。数字版本、时间继续用十进制字符串返回。旧的只读 model-preview 接口保留。

## 页面与后续

用户先查看原始分享，再读取连接目录、选择连接和模型、创建草稿；两个同意复选框均默认为空。详情提供完整分享、期限、状态核对和取消。连接目录与授权历史均支持分页；历史入口可在刷新后重新读取。草稿或批准响应丢失时保留原请求，允许查询或重试同一操作，不自动新建或重发。浏览器本地到期后隐藏分享和批准入口，最终有效性由服务端判定。

请求沿用学习面板的互斥、超时和账户生命期保护；学习来源操作清除已读授权历史，401 和账户切换卸载所有私有内容，晚到响应不能写入新账户。无浏览器持久化存储，正文按纯文本展示。

下一批按顺序交付：

1. 新增一次性领取、发送前来源/连接复核、取消栅栏和未知结果不重派的仓储及夹具验收。
2. 接入现有本地订阅运行时，严格验证返回协议和引用，保存有来源生命周期保护的模型建议。
3. 页面展示建议与原证据的对应关系；仍由用户逐项核验并主动填写自评。真实连接实测须单独选择连接、审阅内容并确认额度。

## 本批验收结果

Rust 格式、Clippy 和工作区测试、前端 lint/typecheck/build 全部通过；162 个存储 PostgreSQL 用例、16 个学习 HTTP 用例（含新增 5 个授权用例）、完整核心 HTTP smoke 和 32 个学习页面双入口浏览器用例通过。桌面/移动端截图已检查，测试栈已清理。HTTP 验收使用真实一次性数据库和可信连接元数据夹具；浏览器授权流程使用连接/授权响应夹具验证交互，不代表真实 OAuth 或订阅模型已调用成功。本地未重跑其他页面全量、对象存储/向量专项、公网或真实模型验收，完整 CI 另行记录。

执行阶段现由[一次性订阅核验执行](learning-model-execution.md)接入，追加 0039 迁移，支持 running/succeeded/unknown 与 advice；保存授权依然不自动执行。本文开头的不派发说明描述 0038 阶段边界，实际发送须显式本地 learning-run 命令，来源失效也会清除已保存建议。
