# 独立本地 RSS 价值评分

当前新授权已采用 [v4 分类协议](rss-classification-v3.md)：三套六轮合成质量与真实保存/恢复已通过，历史版本继续只读兼容。下文保留本阶段的交付记录。

本批按三阶段交付并分别验收提交推送：① 精确本地同意、0041 派发约束及一次发送仓储；② 默认关闭的私有授权 API、显式本机执行命令及双代理；③ 页面、本地真实模型与删除/恢复验收。复用已有 RSS 最小分享、严格完整评分与阅读投影；不改变规则日报、不自动采集，也不调用个人订阅或付费 API。

## 授权和执行

`ValuePricing::Local` 绑定 canonical HTTP loopback 地址、模型、`local-rss-v1` 配置和期限。只接受已保存候选及显式关键词，分享包含系统指令和候选标题/摘要，不含账户、原文 URL 或订阅凭据。摘要还绑定用户、请求、偏好版本、精确候选、配置和到期时间。预览最长五分钟；同一个请求 ID 的重复预览返回原记录，不替换目标或冻结内容。

本地分享总量最多 5632 字节、上下文 8192 tokens、输出上界 2048 tokens，超长材料在保存预览前拒绝，不静默截断。返回缺少、重复或未知条目、非整数/越界分数、非法理由或截断传输均不能成为成功；score=null 保留无法评分语义，输出只用于参考阅读。

必须分别同意分享材料和本地计算；订阅/API 同意不能批准本地请求，本地同意也不能批准订阅/API 请求。不产生金额预留，不建立订阅身份，复用所有 RSS 评分模式合计每天最多 20 个预览、总计 1000 个记录的限制。

一次领取、发送前目标和来源复核、持久化发送标记、严格结果保存均在已有用户隔离/锁协议内执行。并发只有一个领取成功；sent_ms 永不清除。取消、来源/偏好变化、超时和未知结果不能重新派发；晚到结果不保存。恢复继续应用通用 RSS 授权隔离，正常完成结果保留，旧授权不重发。端口使用 `LocalInference`，可在后续满足显存门槛时替换 vLLM。

## 显式命令与配置

设置 `RSS_LOCAL_ENABLED=true` 后可通过私有 `GET /api/feed-values/config` 查询开关；默认 false。`POST /api/feed-values/local` 接收 id、endpoint、model，返回冻结分享预览；`POST /api/feed-values/{id}/approve-local` 必须给出原 digest、acknowledge_sharing=true、acknowledge_local_compute=true。未知字段拒绝，订阅批准端点不能批准本地记录。网页不派发推理，所有接口仍检查会话/CSRF 和归属，Next/Nginx 双入口转发不携带管理员凭据。

先显式 `make local-model-start`，再导出应用 `DATABASE_URL`，运行 `make local-value OWNER=用户UUID REQUEST=原授权UUID`。该入口复用 6 GiB 显存监督、加载/发送门槛及单模型/单并发配置。`local-value show OWNER REQUEST` 只查原记录；直接 `local-value run OWNER REQUEST ENDPOINT MODEL --use-local` 适用于另有独立显存保护的受控运行时，目标不匹配在领取前拒绝。正常终态重复执行只读保存评分，其他终态退出 1，无自动重试、登录或回退到付费模型。通过原私有 detail/reading/audit 接口查询结果，规则日报不变。

本批仅为 RSS 新增已保存结果的阅读，不新增临时正文跨进程通道；学习核验原有临时文本仍独立。后续 vLLM 可替换标准 SSE 适配器，但部署须另行核对显存和完整协议。

## 页面与真实模型验收

在“RSS 价值评分”选择“本地模型”，显式读取配置后填写回环地址/模型；只读开关关闭时不能创建授权。先预览冻结内容，再分别勾选分享与本地计算同意。修改目标会清除当前审阅和勾选；响应丢失时保留原请求及目标，通过查询核对，重试预览仍用原 ID 和原输入。网页不启动服务或发送推理请求。完成评分后使用原阅读视图；来源变更、退出及晚到响应沿用现有清理保护。

显式启动保护服务后运行 `make recovery-acceptance-rss-local`。该入口在一次性 PostgreSQL 中通过真实 API 创建合成订阅/偏好并批准，注入固定三条短 RSS 夹具，不联网采集；受保护命令调用官方 llama.cpp/Qwen。错误目标在领取前拒绝，严格评分落库、重复执行只读、阅读隔离及原规则不变均需成立。备份到空库恢复后，开关仍默认关闭，完成阅读可查询、旧待执行授权作废；删除来源清除评分且不重发。其实际效果验证协议和生命周期，不代表真实用户材料的排序质量或游戏峰值压力。

阶段 3 的真实模型及恢复演练已通过；监督器随后停止，空闲显存为 14605 MiB。前端 lint/typecheck/build 通过。生产 API/Web 镜像、完整 core smoke、166 项仓储、6 项评分 HTTP 和 26 项 RSS 双入口浏览器全部通过（新增 8 项本地用例），桌面/手机授权截图已检查，隔离资源已清理。本阶段未重跑其他页面专项、外部原文/向量扩展或完整浏览器；最新完整远程 CI 状态另行核对。
