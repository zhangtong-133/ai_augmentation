# 独立本地 RSS 价值评分

本批按三阶段交付并分别验收提交推送：① 精确本地同意、0041 派发约束及一次发送仓储；② 默认关闭的私有授权 API、显式本机执行命令及双代理；③ 页面、本地真实模型与删除/恢复验收。复用已有 RSS 最小分享、严格完整评分与阅读投影；不改变规则日报、不自动采集，也不调用个人订阅或付费 API。

## 授权和执行

`ValuePricing::Local` 绑定 canonical HTTP loopback 地址、模型、`local-rss-v1` 配置和期限。只接受已保存候选及显式关键词，分享包含系统指令和候选标题/摘要，不含账户、原文 URL 或订阅凭据。摘要还绑定用户、请求、偏好版本、精确候选、配置和到期时间。预览最长五分钟；同一个请求 ID 的重复预览返回原记录，不替换目标或冻结内容。

本地分享总量最多 5632 字节、上下文 8192 tokens、输出上界 2048 tokens，超长材料在保存预览前拒绝，不静默截断。返回缺少、重复或未知条目、非整数/越界分数、非法理由或截断传输均不能成为成功；score=null 保留无法评分语义，输出只用于参考阅读。

必须分别同意分享材料和本地计算；订阅/API 同意不能批准本地请求，本地同意也不能批准订阅/API 请求。不产生金额预留，不建立订阅身份，复用所有 RSS 评分模式合计每天最多 20 个预览、总计 1000 个记录的限制。

一次领取、发送前目标和来源复核、持久化发送标记、严格结果保存均在已有用户隔离/锁协议内执行。并发只有一个领取成功；sent_ms 永不清除。取消、来源/偏好变化、超时和未知结果不能重新派发；晚到结果不保存。恢复继续应用通用 RSS 授权隔离，正常完成结果保留，旧授权不重发。端口使用 `LocalInference`，可在后续满足显存门槛时替换 vLLM。
