# 训练证据订阅核验执行与建议回看

在[精确授权](learning-model-authorization.md)之上追加 `0039_learning_model_execution.sql`：一次性领取、持久化发送标记、受限模型建议与来源撤销。复用本地订阅传输，提供显式 `learning-run` 命令；没有后台自动领取或网页发送接口。批准本身仍不调用模型。

## 一次发送与故障边界

内部 `ModelReviewExecutionStore` 提供 claim/begin/finish 三步，使用与来源修改、授权取消、连接撤销相同的用户行锁：

1. claim 只领取仍有效的 authorized，冻结原授权，保存随机派发 token 和最多 90 秒、且不超过原授权到期时间的期限；转为 running。并发或进程重启后不能再次领取。token 不序列化，也不通过 HTTP 接收或返回。
2. 执行器最多花 10 秒核对本地账户和模型目录。begin 再读来源、连接版本和授权摘要，核对本地 host/client/subject 身份、模型与令牌有效期，并在事务内保存不可重置的 sent_ms 和 sending 审计。这是允许发送的线性化点。提交不确定时不发送或重试。
3. 提交发送标记后最多等待 60 秒的一次模型调用；无自动重试，无 API 金额回退。finish 再检查来源、取消和期限，只在发送标记存在且完整返回通过校验时保存建议。供应商错误、超时、缺字段、错摘要或伪造引用均为 unknown；不保存原始错误或无效输出。

取消或撤销若先于 begin，则不会发送；若发送已开始，取消不能撤回供应商请求，但后续结果会被丢弃，额度可能仍消耗。崩溃或丢失 future 后，下一次读取/列表/执行操作把超过派发期限的 running 转为 unknown，永不恢复授权。持久化建议失败会保留 running 和发送标记，不能再次调用模型；已收到的输出可以重试本地持久化，但普通命令不自动重试。

## 建议及生命周期

建议用独立 advice 字段返回，完整保存协议版本、输入摘要、四项 verdict/reason/citations；没有数值分数。仅保存 `learning-model-review-v1` 验证通过的结果，并在读接口重建原始预览后再次校验；绑定被破坏或建议损坏则 invalidated 并清除 advice。存储不复制原始证据正文，引用作为派生内容随建议清除。

状态新增 running、succeeded、unknown。取消 running 会丢弃晚到结果；取消 succeeded 会清除已保存建议。已成功建议不因五分钟的“允许开始执行”期限到期而消失，但仍要求来源和连接有效。连接更新/撤销/到期、证据或计划删除使相关建议失效；技能更新/删除或自评撤销沿用保守策略，使该用户所有活动或成功核验失效并清除建议。账户删除清理授权和审计。不删除独立训练记录或自动撤销无关自评。

精确批准的幂等重试在 running/succeeded 时返回当前状态，保留原批准时间，不重新授权。HTTP 仍只有已有会话/CSRF 授权管理及私有查询端点，没有执行入口。

## 本机显式执行

先在页面预览并批准；使用已登记到同一用户的本地账户，提供数据库配置：

```sh
cargo run -p api-server --bin chatgpt-connect -- PRIVATE_DIRECTORY learning-run LABEL USER_UUID REQUEST_UUID --use-subscription
cargo run -p api-server --bin chatgpt-connect -- PRIVATE_DIRECTORY learning-show USER_UUID REQUEST_UUID
```

两个命令都要求 `DATABASE_URL`。只有 learning-run 在原请求为 authorized 时读取本地私有凭据；先持久化必要的令牌轮换，再持有同一账户文件锁完成验证、发送和结果保存。运行命令不创建或批准授权；终态重试不发请求，非成功结果返回失败退出码并要求核对原记录。learning-show 只查询原记录，不读取凭据。

本地运行时复用既有订阅验证和单次 Responses 传输，仅传固定系统消息及冻结的 input JSON。temperature/max_output_tokens 均不设置，没有承诺供应商用量上限；本地时间/响应字节限制不是额度上限。可能消耗订阅额度或账户设置允许的 credits。日志不输出凭据、派发 token 或原始供应商错误。

## 页面及下一阶段

授权历史显示执行中、建议已保存、结果未知；仅手动核对状态，不轮询或重发。成功建议逐项显示判断、理由和原文引用，明确标注仍需人工核验，并可回到原训练证据；不自动填入人工核验或自评分数。未知结果只解释状态，新尝试必须重新预览授权。成功建议在授权开始期限过后仍能显示，取消或失效后清空正文；登录失效和账户切换沿用原有保护。

代码闭环为：结构化证据 → 精确分享与订阅用量授权 → 本机单次执行 → 引用绑定建议 → 人工核验和显式自评。真实 Pro 连接实测未包含在开发授权中。下一阶段先补充执行运维与一次真实连接的用户验收，再推进流式交互及其他 v1 集成项；API 金额路径保持独立可选。
