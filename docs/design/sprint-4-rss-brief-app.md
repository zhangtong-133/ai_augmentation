# Sprint 4：Daily Brief HTTP 与页面

本步将日报偏好与不可变计划仓储接入现有 RSS 应用装配。登录用户可保存关键词，显式生成当日规则日报，分页查看历史、读取详情或删除正文。无需启用公网采集模式，不调用来源、模型、通知或后台调度。

## HTTP 边界

| 路径 | 方法 | 输入 / 行为 |
| --- | --- | --- |
| `/api/feed-brief-preferences` | GET | 当前用户偏好及版本 |
| `/api/feed-brief-preferences` | PUT | `revision` 十进制字符串、`keywords` 数组；比较版本后保存 |
| `/api/feed-briefs` | GET | 可选 `after` UUID，最多 20 条元数据 |
| `/api/feed-briefs` | POST | `request_id` 非零 UUID、`preference_revision` 十进制字符串；创建或返回原记录 |
| `/api/feed-briefs/{id}` | GET | 当前用户保存的不可变计划或失效/删除墓碑 |
| `/api/feed-briefs/{id}` | DELETE | 空 JSON 对象，清除正文并保留墓碑 |

所有接口校验会话，写操作校验 `X-Requested-With: personal-ai` 与既有 CSRF 边界；响应设置 `Cache-Control: no-store`。输入拒绝未知字段、伪造候选、调用方时间/用户、非规范版本和超长请求。沿用 16 KiB 请求上限。版本允许 0，最大为 PostgreSQL BIGINT；版本和毫秒时间在响应中使用十进制字符串，避免 JavaScript 精度损失。

Next.js 代理仅允许上述路径与方法，保持 cookie 和 CSRF 头，不代客户端添加授权头；Nginx 与 Next.js 入口使用相同 API。用户无权读取的记录返回 404，输入错误返回 400/422，偏好冲突、候选超限或额度已满返回 409，仓储不可用返回 503。不会向浏览器返回内部 SQL 或错误细节。

## 页面

账户区域新增 Daily Brief 日报面板。关键词每行一个，最多五个；未保存修改时禁止生成，确保本次生成使用页面已确认的偏好版本。留空只按新鲜度排序。界面说明 UTC 日窗口、每天最多十份与每份最多二十条，显示历史、结果、关键词命中位置和分数，以及空结果说明。

来源标题和摘要按纯文本渲染；仅允许无用户名/密码的 HTTPS 外链，打开时不发送 referrer。不会加载来源图片或执行嵌入标记。

所有写操作在发送前保存完整原操作。响应丢失时可查询或重试原操作；生成重试使用相同请求 ID 和偏好版本，避免重复创建。偏好保存丢失时，查询回填服务器当前内容；版本已变化需要重新核对。查询不会自动重发写请求。历史可在刷新后继续核对；页面不将正文、关键词、cookie 或未完成请求保存到浏览器持久化存储。

删除日报需要二次确认；失效或删除详情不再展示正文。当前页删除 RSS 订阅成功后，日报面板立即中止旧读取、清除详情并重新加载状态，避免晚到响应重新显示已清理的正文。外部变更通过显式刷新或更新日报状态读取。每个账户独立挂载面板，退出时中止请求；401 清空私有状态并禁用操作，旧账户响应不能写入新账户。

## 验证

HTTP 集成测试覆盖会话、CSRF、未知字段、请求上限、版本精度、所有权、偏好 CAS、幂等生成、快照读取、删除来源后失效，以及公网采集关闭时的本地生成。传输计数确认日报操作不会新增网络请求。

Playwright 使用真实应用和一次性数据库，验证 Next.js 桌面与 Nginx 移动入口的偏好、生成、重载、删除和账户隔离；故障夹具验证丢失响应后原请求重试、偏好结果核对、晚到数据隔离、分页、纯文本渲染与登录过期清理，并保存两种视口截图。沿用 Rust 检查、前端 lint/typecheck/build 和完整 browser-test（含 PostgreSQL、HTTP smoke）。

本步无新增迁移或环境变量。后续 [Skill Graph、自评与训练计划纯规划](sprint-4-learning-planning.md)已实现，接下来落地学习仓储。
