# 训练证据与能力反馈

## 本轮交付边界

训练结果是用户填写的记录，不是能力证明。先提供只读证据检查：逐项关联原计划、任务、技能版本及结果请求，区分未记录、已取消、缺少文字记录和待人工核验。耗时、完成次数、备注长度均不换算成分数。检查不调用模型、不写数据库、不改变自评。

检查随计划详情返回，由当前仍可读取的计划和结果重新生成；不复制备注。删除计划或来源技能后，正文、结果与检查条目一并消失。旧计划仍然表示生成时的技能版本，不能当作当前技能的评估建议。用户可展开每项检查并直接回看同一任务的原始记录。

## 后续评估协议（尚未实现）

证据必须绑定 owner、计划 ID、任务 ID、结果请求 ID、技能 ID 与技能版本；至少包括具体练习产物、验证过程和可复查结果。自由备注只能作为待核验证据，不能因为非空就宣称证据充分。

量表按四个维度审阅：概念解释是否准确、能否独立完成练习、能否用可复现检查验证结果、能否说明局限或反例。每项状态为缺少证据、待核验或有证据支持；缺少材料时不给出总分或提升结论。量表版本、引用和逐项理由必须保存，外部链接不自动抓取。

持久化建议采用待确认、已确认、已失效状态。确认必须显式提交用户选择的自评分数、建议 ID、预期学习快照版本和技能版本；在同一事务中重新核对证据有效性。模型建议不等于客观能力分数，也不直接替换自评。重复请求幂等、不同内容冲突；来源删除清除衍生正文并使建议失效，不能通过重试恢复。

后续门槛：跨用户访问拒绝；修改技能或自评后旧确认冲突；删除证据后不能确认；并发确认只生效一次；没有证据和仅记录完成不产生分数；页面退出、失效和晚到响应清除私有材料。
