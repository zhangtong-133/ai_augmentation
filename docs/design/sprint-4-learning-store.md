# Sprint 4：技能图、自评与不可变训练计划仓储

本步新增 `LearningStore`、PostgreSQL 实现和迁移 `0026_learning.sql`，将纯规划库接入持久化技能图、自评及计划/任务事务。尚未提供学习 HTTP、页面或任务完成操作；无模型、通知、Scheduler 或后台执行。

## 技能图与版本

`learning_snapshot` 在用户行锁保护下返回该用户的完整有界技能图、自评集合和快照版本。未保存任何内容时快照版本为 0。每次有效技能增改删或追加自评递增版本，创建计划、读取和原请求重试不递增。所有学习写操作复用同一用户行锁，串行化图与自评变更、额度判断和生成。

`save_skill` 使用非零 UUID 标识技能：预期技能版本 0 表示创建，否则比较当前技能版本再修改。创建原 ID、规范化内容相同且仍为首版时返回原技能；版本匹配且内容未变时不递增。更新名称、启用状态或先修关系均递增技能版本；旧自评保留，但不再作为该技能当前版本证据。删除后的技能 ID 不能复活。

每次写入前复用 `normalize_skill_graph` 验证整个候选图，拒绝跨用户/缺失先修、自引用、重复边、环和超限；不会只检查当前节点。两个并发修改试图建立互相依赖时，至多一个成功，另一个回滚。

技能最多 100 个，包含删除墓碑。数据库读取最多 101 个节点、每节点最多 9 条边，以探测纯规划器的 100 节点/8 先修上限；超限明确失败，不能返回被截断的图。

## 显式自评

`record_assessment` 输入独立请求 UUID、预期快照版本、技能 ID/版本及 0–100 分。仅启用、未删除且版本匹配的当前技能可提交。时间由数据库时钟产生，调用方不能提供。首次写入比较快照版本；相同请求重试先核对原始参数并返回原记录，即使图或自评后来变化也不重新采样时间。请求参数不符或记录已被删除清理时拒绝。

每用户最多 1000 条自评记录，包括分数已清除的墓碑；删除不能重置额度。读取最多 1001 条未清除记录用于探测上限。数据库限制同技能、同版本、同毫秒只有一条自评，避免产生矛盾的最新证据；极近的不同提交冲突时返回 Conflict，不虚构未来时间。只有成功写入自评才增加快照版本，评分不会由练习安排或任务状态推断。

## 不可变计划与任务

创建输入包含请求 UUID、预期快照版本、5–180 分钟预算及 1–10 个目标 UUID。目标规范化、排序并拒绝重复。首次生成在用户行锁下核对版本，用数据库时钟加载图和自评，调用纯规划器，在一个事务中保存：

- `learning_plans`：计划 JSON、输出摘要、请求参数摘要、快照版本及生成时间。
- `learning_plan_sources`：本次输入图中全部技能，包括非目标和停用/删除节点，用于派生内容清理。
- `learning_tasks`：最多 5 个任务的独立定义、顺序及 `planned` 状态，为后续显式结果记录提供持久化基础。

任务写入失败会回滚计划和来源关联。只安排自评或练习，不表示任务已经完成，不修改自评、不解锁先修技能。

同 owner/request 重试核对原请求参数摘要后返回原记录，先于当前快照版本和额度检查。技能或自评变化、跨日、满额都不会使原请求重算。原请求改预算、目标或预期版本则冲突。历史快照不会因技能改名而改写。

每用户每天（UTC）最多 10 份计划，总计最多 1000 份；删除/失效记录均计入额度。历史按 UUID 游标每页最多 20 条，仅返回请求、时间和状态。详情读取验证已知规则版本、owner、请求、时间、输入参数摘要、计划摘要，并逐项核对任务行的 ID、顺序、状态和定义。计划与任务不一致时拒绝返回。数据库内部反序列化拒绝未知字段；未来 HTTP 必须使用独立输入 DTO，不能接受客户端计划。

## 删除与隔离

技能软删除保留递增版本的墓碑、固定名称“已删除技能”，关闭启用并移除该节点自己的先修边；其他技能对它的依赖仍保留，因此保持阻塞。原自评分数清空，保留请求、版本和时间元数据以防复活及额度重置。

数据库触发器在技能软删除或硬删除时，将输入图包含该技能的 ready 计划标记 invalidated，并清空整份计划及其全部任务定义。任务状态同步变为 invalidated；不会局部改写快照后继续当作原计划使用。即使删除的技能不是目标或被选中的训练对象，也执行这项保守清理。

显式删除计划将计划与任务正文清空并标记 deleted，删除来源关联，保留请求墓碑和额度；原请求不能复活内容。账户删除级联清理全部学习数据。跨用户技能边、自评和计划来源使用复合外键隔离；仍被其他技能引用的节点不能单独硬删除，正常技能删除走软删除路径。

事务协议覆盖应用层操作。管理员直接修改表不是受支持的图/版本编辑接口；删除触发器额外保证直接删除时的派生正文清理。当前没有自动保留期清理或额度归还。

## 验证与下一步

新增真实 PostgreSQL 测试覆盖：技能版本及并发循环、快照 CAS、显式自评与幂等、旧版本自评失效、计划冻结与重启读取、账户隔离、任务定义篡改、来源删除与生成竞争、非目标来源清理、软/硬删除和账户级联、每日/总量/技能/自评配额、分页、超限/未来快照拒绝、任务写入故障以及版本递增失败时的完整回滚。

下一步接入学习管理 HTTP、页面与用户显式训练结果记录。任务完成或取消应有独立版本/幂等控制，并与显式自评分开；完成练习不得自动提高分数或派发新任务。
