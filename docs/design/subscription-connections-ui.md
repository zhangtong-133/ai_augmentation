# 订阅连接管理页面

登录后的账户面板提供 ChatGPT 订阅连接列表、详情和显式撤销，使用[已有管理 HTTP](subscription-connections-http.md)。本页不创建或续期连接、不上传凭据、不调用模型；首次登录和绑定仍通过本地工具完成。

列表每页最多 10 条，可前进或刷新回第一页。标签、模型和版本仅按文本展示；到期时间包含本地时区，登记期限已过的 active 记录在页面显示为已到期。“已绑定”不证明额度充足或真实调用可用。

查看详情会重新读取服务端状态。撤销前必须勾选确认，提交精确 revision 和 CSRF 头。撤销会使应用连接及相关评分授权失效，不会取消订阅或退出 ChatGPT。页面提供 OpenAI 用量设置链接供用户管理其侧授权。

撤销的网络失败、版本冲突或异常返回都进入待核对状态，保留连接标识，禁止自动重发及切换列表。用户通过“核对连接”查询：已撤销则完成；仍有效或版本更新则清除旧勾选，要求再次审阅确认；不存在则移除。不会自动用新版本撤销。

请求限制为 10 秒，并在组件卸载时中止。以账户 ID 为组件键，退出或切换账户清空组件状态；晚到响应不能写入新账户。401 清除已显示的连接和详情并停用操作，提示重新登录。列表错误保留错误提示而不伪装为空列表。

`tests/browser/subscription-connections.spec.mjs` 在真实应用会话下使用确定性元数据/故障夹具，覆盖精确撤销版本、409 后重新确认、已执行但响应丢失后的查询恢复、分页、401、账户隔离、文本转义及移动端布局，并生成截图。真实数据库与双代理 HTTP 行为由既有 smoke 验收覆盖。尚未验证真实 Pro 账户。RSS 评分现通过[本地显式命令](rss-value-local.md)发起，本页面没有评分授权或执行入口。
