# Sprint 4：学习进度概览

在学习管理页面增加只读进度卡片和 `GET /api/learning/progress`，帮助用户查看当前自评覆盖、待记录训练和今日记录。复用现有学习数据，不新增迁移、后台任务、模型调用或配置开关。

## 统计口径

`LearningStore::learning_progress` 使用同一个 `REPEATABLE READ, READ ONLY` 事务读取当前用户的数据。先建立用户快照，再采样数据库时钟；每条查询限时 5 秒，不锁住写入者。服务失败不返回伪造的零统计。

| 字段 | 口径 |
| --- | --- |
| `enabled_skills` | 已启用且未删除技能数 |
| `assessed_skills` | 上述技能中，当前技能版本存在未清除自评的数量；只取截至快照时间的最新自评 |
| `target_reached_skills` | 最新自评分数达到规划器 `TARGET_SCORE` 的技能数；参考分数在 `target_score` 返回 |
| `ready_plans` | 仍保留正文的 ready 计划数 |
| `historical_plans` | ready 计划中快照版本早于当前学习版本的数量 |
| `pending_tasks` | ready 计划下 planned 任务中尚未记录完成/取消结果的数量，包含历史计划任务 |
| `completed_tasks` / `cancelled_tasks` | 上述计划任务中当前保留的完成/取消结果数量 |
| `completed_today` / `cancelled_today` | 结果记录时间位于当前 UTC 日且不晚于快照时钟的完成/取消数量 |
| `recorded_minutes_today` | 今日完成记录的实际分钟总和，包含练习和自评准备；取消不计用时 |

修改技能名称、启用状态或先修关系后，其旧版本自评不计入当前覆盖率。最新自评可能低于先前分数，不取最高分。停用/删除技能不计入启用数或覆盖率。参考目标复用纯规划器常量（当前 70），不把自评目标达成解释为客观能力或先修条件已满足。

今日按数据库时钟所在 UTC 日的 `[00:00, 次日 00:00)` 统计，边界与快照时钟通过 `day_start_unix_ms`、`day_end_unix_ms`、`as_of_unix_ms` 返回；未来记录不计入今日统计。UTC 对应北京时间 08:00 至次日 08:00。本接口不接受客户端日期、时区或用户参数。

这是现存有效记录的统计，不是不可删除的历史累计。删除计划、删除来源技能导致计划失效或删除账户后，对应训练结果不再统计。技能改版后仍可记录历史计划的练习，因此待记录数包含历史计划；生成多个计划会产生多个独立任务，不自动去重或合并。完成训练不自动提高自评分数。

## API 与页面

接口使用当前会话用户，认证失败 401；未装配学习存储或数据库不可用 503。只支持 GET，拒绝未知查询参数，响应及错误均 `Cache-Control: no-store`。UTC 日期、时间和学习版本以十进制字符串返回，计数为 JSON 整数。响应不包含技能名称、评分明细、计划正文或训练备注。Next 同源代理只新增此 GET 路径，Nginx 复用既有 API 转发。

卡片位于学习管理顶部，显示自评覆盖、待记录训练、今日完成/取消和用时，以及更新时刻、学习版本和历史计划数。显式刷新、技能/自评/计划/结果写入成功及原操作核对时更新统计；刷新前清除旧数据。独立进度刷新不清空用户正在编辑的表单。

进度查询失败时显示独立错误和重试按钮，清空旧计数，仍允许已加载的技能与计划管理。401 清空整个学习面板的私有数据和未完成操作，并禁用操作直到重新登录。沿用串行请求、超时、AbortController 和按账户 ID 重建组件，旧账户晚到响应不能进入新账户。进度刷新只读，不自动轮询或重新提交训练记录。

## 验证

- PostgreSQL：空账户、账户隔离、最新自评、技能改版/停用、参考目标、历史计划、完成/取消、删除清理、UTC 左闭右开边界及未来记录、并发删除的一致快照。
- HTTP：会话隔离、只读方法、拒绝用户查询参数、no-store、版本大于 2^53 时保持精确字符串，不返回技能正文。
- 浏览器：真实学习操作后计数更新、删除后清零、进度失败不阻塞管理、重试恢复、401 清除全体学习数据、旧账户晚到统计丢弃，以及桌面/移动布局检查。

这些统计不替代管理员 `learning-operations` 的一致性诊断，也不重新验证不可变计划摘要。

本轮验证通过：Rust 1.98 全仓 `make check`、前端 lint/typecheck/build、133 项 PostgreSQL 回归、学习 HTTP 测试，以及完整 `make browser-test` 的镜像/HTTP/桌面和移动端验收（82 项通过，8 项索引与真实公网可选场景按配置跳过）。两种布局截图已检查，隔离容器、网络与数据卷已清理。本轮未另跑对象存储或索引专项。
