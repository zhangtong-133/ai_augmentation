# Sprint 3：Agent 检索计划页面

## 范围

在当前对话消息下方提供固定 `knowledge-search-v1` 计划的编排、预览、明确授权、历史结果和取消。沿用[计划 API](sprint-3-agent-plans.md)及已有索引配置，不增加迁移或环境变量。

用户填写 1–3 个互不重复的查询和每步 1–5 个片段上限，成功读取已有消息版本后才能保存预览。预览展示服务端保存的查询、顺序、工具、消息版本、计划 ID、指纹和调用上限。编辑表单只影响下一个新计划，不改变已有预览。

## 费用与授权

保存预览不调用模型。用户点击“审阅并授权此计划”后再次查看完整步骤，并主动勾选费用确认，才能发送精确指纹、次数上限及 `acknowledge_embedding_cost: true`。确认框每次打开都重新勾选；授权正文取自已保存的预览。

授权后每步可能调用向量模型并计费，共享工具 UTC 日 100 次尝试预算。这个版本仅限制调用次数，没有金额报价或货币预算；页面明确说明该边界。模型规划、聊天回答、记忆写入和自动调度仍待实现。

消息版本变化、无消息、读取失败、知识检索关闭、页面不支持的计划版本或过期草稿不能新授权。服务端仍是版本、授权及额度的最终判断方。草稿到期时页面本地更新状态，无需轮询或发送写请求。

## 请求与恢复

- 保存预览使用新 UUID；保存、授权、取消均冻结原计划 ID、路径和正文。失败不自动重发，仅由“重试计划原请求”显式重试。
- 刷新历史可以确认已保存的定义、相同指纹和次数的持久化授权，或已取消/完成的终态；确认后清除本地待确认请求。读取故障或不匹配的记录不能解除待确认状态。
- 审阅/取消确认、正在写入及结果未确认期间，禁止发送消息、新建回复、切换或删除当前对话。仍可返回列表，或在写入结束后刷新计划历史核对。
- 放弃未确认请求需再次确认，只清除本地状态。整个页面刷新或退出会丢失本地待确认请求；已接受的计划可从服务端历史恢复，已授权的执行仍可能继续计费。新计划需要再次保存和授权，可能重复计费。
- 只在历史包含 `running` 时每 2 秒读取。终态和读取故障停止轮询；故障保留旧历史并标明可能过期，等待手动刷新。
- 切换对话、删除或账户退出时卸载面板、取消读取并忽略晚到响应。私有查询、结果和待确认正文只保存在组件内存中。

## 取消与结果

取消需二次确认，清除计划已保存的输出并阻止后续步骤。已派发的调用可能继续计费，已登记次数不会退还；完成、失败等终态按服务端原状态返回。退出登录或关闭页面仅停止页面请求，不撤销已授权的后台步骤。

显示计划和步骤状态、尝试次数以及经服务端归属复核的知识片段。查询、标题、来源和原文均按纯文本呈现，原文可展开，长内容换行。不会把故障显示成没有资料，也不把检索得分当正确率。

页面校验成功响应的用户对话归属、固定工具、步骤数量/顺序、查询边界、指纹、状态及有界结果结构。无效响应保留旧历史并禁用新授权；最终权限由会话、CSRF 和后端事务保证。

## 验证

`make browser-test-index` 在 Next.js 桌面和 Nginx 窄屏两个项目执行：

- 真实 PostgreSQL/Qdrant 和本地向量模型夹具：三步预览、服务端接受后丢失响应的原 ID/授权重试、确认绑定已有预览、历史恢复、原文纯文本、取消响应丢失后的读取确认，以及截图与横向溢出检查。
- 受控网络响应：未启用能力、查询边界/重复校验、消息版本变化、不支持版本、草稿本地到期、无效历史、取消失败后显式重试、终态/故障/退出停止轮询，以及切换对话/退出/删除后的晚到数据隔离。

不含索引环境的 `make browser-test` 执行全部故障用例，真实计划执行用例按能力条件跳过。后端归属、预算、取消竞争和重启查重由既有 PostgreSQL、HTTP 及 smoke 验收覆盖。
