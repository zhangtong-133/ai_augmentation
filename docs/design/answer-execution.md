# 本地问答单次执行与结果恢复

2026-10-22：本批将[现有精确预览与授权](answer-authorizations.md)接入独立、显式的单次执行闭环。先交付供应商无关的执行生命周期、权限保护和页面，再按用户选定的具体模型独立验收质量。工程开发不再以本机 Qwen 在全部合成题上通过为前置条件；历史实验成绩、失败和原门槛保持。

## 产品边界

页面依次执行“创建精确预览 → 双重确认并保存授权 → 用户另行点击执行一次”。保存授权、刷新记录、恢复详情或重新登录均不发送模型请求。继续使用既有 v2 完整请求、目标、材料和摘要绑定；不把 Ollama 实验候选接入现有 v2 授权，也不复用不同模型或协议的同意。

部署默认关闭执行。服务端显式配置执行能力后，页面才允许对仍有效且未领取的授权点击执行。模型输出标注为待用户核对；逐字引用与合法协议不保证语义正确。本批工程验收使用确定性模型夹具，不宣称真实模型质量或私有材料实测已通过。

## 单次领取与持久化

授权状态与执行状态分别保存。服务器以当前所有者、摘要、期限、会话和权威来源复核作为领取条件；事务提交单次领取后才允许交给执行器。并发点击、页面刷新或请求丢失不能产生第二次发送。已领取的授权不能恢复为 authorized；结果未知、失败或超时也不能重发原授权。

执行前后复核会话、来源、完整请求指纹与固定目标。取消、退出、来源变化或执行失败时不能保存或展示晚到答案。存储只暴露属于当前用户且来源仍有效的结果；读取记录不会重新执行。未知发送结果保留已消费事实，前端仅提供查询原请求。

领取、唯一发送标记及结果终态均有事务审计；审计写入失败会回滚对应事务。持久化执行截止时间最多为领取后 90 秒，并且不超过原授权期限；进程停止后不会自动恢复派发，后续读取将过期运行记录置为 unknown。取消先尝试原子撤销未领取授权；若执行刚好先领取，则继续取消其执行记录，避免用户取消丢失在两个状态之间。

结果包含纯文本答案及经过生产引用校验的精确摘录和位置。证据不足单独表示，不能伪装成空白成功答案。失效、取消和失败记录不返回问题、材料或已清除的结果正文；历史列表只返回有限元数据。

## HTTP 与页面

执行入口为 `POST /api/knowledge/answer-authorizations/{id}/execute`，正文仅 `{ "digest": "…" }`，继续要求会话、CSRF 与原请求所有者。首次成功领取返回 `202` 和完整授权详情，后台本次执行最多 55 秒；重复执行入口只返回当前状态，不再发送。未配置执行器返回 `503 answer_execution_disabled` 且不消费授权，当前固定目标与完整预览请求不匹配返回 `409 answer_execution_target_changed`。

详情和列表顶层的 `execution_available` 仅表示当前部署配置，不代表服务探测成功、质量通过或自动执行许可。每条授权带 `execution: null | object`；对象包含 `status`、`request_sha256`、开始/截止/发送/结束毫秒时间及可空的 `question`、`result`。执行状态为 `running`、`succeeded`、`failed`、`unknown`、`invalidated` 或 `cancelled`；有执行记录时外层授权始终保持 `consumed`。列表的 `preview`、执行问题和结果始终为空，正文须单独 GET 原详情恢复。

成功结果复用知识问答的 `answered` / `insufficient_evidence` 协议和完整精确引用。引用位置按 Unicode 字符计数，前端拒绝错位、原文不符、歧义摘录、重复引用 ID 和非成功状态携带正文。运行中使用原请求取消入口；成功后同一入口表现为“删除本次结果”，清除问题和结果正文并保留已消费事实。来源失效后读取同样清正文。

面板保留精确分享预览、两个默认未选的同意项、保存与取消。单次执行另设独立按钮；运行期间可取消并隐藏旧正文，响应晚到、组件卸载或账户切换后丢弃响应。执行请求丢失或等待超时后只提示状态尚未确认，不提供自动重试。刷新记录、查询原请求和打开历史详情只进行 GET。

答案与来源以 React 文本节点展示，不解释 HTML 或 Markdown，不把临时内容当作已保存结果。精确摘录展示原文高亮位置，明确说明仍需用户核对模型结论。

## 工程与模型验收分离

工程验收覆盖：预览与双重确认不发送；单独点击至多发送一次；并发、失败和未知结果不重发；取消、退出和来源撤销阻止晚到正文；持久化状态及结果可刷新恢复；用户隔离、严格协议、精确引用、部署关闭和错误格式拒绝。真实数据库/HTTP 与 LocalAnswers SSE 夹具负责服务器工程闭环；浏览器契约夹具负责新状态、纯文本和交互，真实授权用例保留来源和用户隔离验收。
