# 周期 RSS 配置与同意页面

登录工作台新增“周期 RSS”，接入已有[用户授权 HTTP](rss-schedule-http.md)。按账户 ID 挂载独立组件，提供订阅选择、开始/结束时间、1/6/24 小时间隔、不可变预览、明确同意、取消、分页历史及私有审计。不新增迁移或部署变量。

## 用户流程

先添加或启用订阅，再刷新周期 RSS、选择订阅并输入本地时间。时间转为毫秒十进制字符串发送；客户端检查至少五分钟后开始、结束晚于开始且不超过未来七天，服务端再次校验。默认间隔 24 小时，不默认选择订阅或勾选同意。

预览展示保存的源 URL、订阅版本、起止时间、间隔、最多次数、同意期限，以及固定单次读取限制。用户必须勾选同意来源、频率、期限和次数，提交保存的摘要及周期请求同意字段。页面读取、刷新、重审或操作后均清除勾选。浏览器每秒检查同意期限并禁用过期确认；服务端时间是最终依据。

“已授权”只代表授权已保存，不表示 scheduler 在线。页面明确说明后台默认关闭、需要部署者独立启用，手动采集开关也不能证明后台状态。每个时段仅在开始后的十分钟内派发，错过不补发，失败不自动重试，与手动采集共享额度。修改、停用或删除订阅会使旧授权失效；取消无法撤回已发送请求。

## 中断与隐私

同一组件内请求串行；写操作先保存原 ID/载荷。预览和取消失败可以重试原操作，批准失败只允许查询原计划，不能直接重发批准。查询成功后展示服务端状态、清除不确定提示，并要求重新审阅。刷新/关闭提示不会取消授权。请求超时和查询失败保留核对入口，不新建替代请求。

卸载或切换账户会终止请求，迟到响应不得写入新账户。401 清空组件的来源、历史、表单、选择和待核对操作，并中止并行读取，防止另一响应恢复私有状态。所有远端文字使用 React 文本输出，不解析 HTML。表单、状态和确认区域有独立无障碍名称，沿用 RSS 样式并补充可收缩的下拉框。

## 验证

新增 Playwright 用例通过真实数据库/HTTP 验证授权持久化、刷新、取消、隔离和订阅变更失效；响应丢失用例在服务端真正完成保存后丢弃响应，检查原 ID 和批准只查询。分页、过期和迟到响应采用传输夹具验证边界。桌面 Next.js 与手机反向代理共用用例，并导出周期授权截图；测试栈后台默认关闭，不向真实 RSS 源发送请求。
