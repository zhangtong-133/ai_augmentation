# 只读 GPU 观测

`make local-gpu-observe DURATION=30 SCENARIO=unspecified` 明确采样一段时长并生成报告，不启动模型/游戏、不分配 GPU 内存、不接管或停止任何服务。复用 `readGpu` 对 GPU 0 的 NVIDIA CSV 查询（单次 2 秒时限），查询顺序执行，完成后最多等待 500 ms 再查询。时长为 1–3600 秒；默认 30 秒。真实查询延迟计入观测，最长采样间隔和实际持续时间始终保存，不把名义间隔当作实际频率。

场景可选 `unspecified`、`model`、`game`、`game-model`，只是用户标签。报告明确 `game_activity_verified=false`、`model_activity_verified=false`、`continuous_peak_verified=false`；工具不读取进程名、游戏名称、命令行或账户。采样峰值可能漏过两个样本之间的瞬时峰值，未测 FPS/卡顿，也不构成显存硬隔离。

## 报告与退出码

每次写入 `.local-model/observations/run-…/report.json`，新目录 0700、文件 0600，不覆盖已有结果。包含 GPU UUID/名称/总显存、首末剩余、采样最低剩余与最高占用、样本/查询数、最长间隔、UTC 起止和单调时钟持续时间；不保留原始 CSV、底层错误或每个样本。脚本及预算/运行配置 SHA-256 记录实现来源。

分别统计低于 6144 MiB（用户要求）和低于 6656 MiB（监督器加 512 MiB 缓冲）的样本。观测完成且未低于监督阈值退出 0，任意样本低于监督阈值退出 2。查询错误、非法读数、GPU UUID 或总容量改变立即结束并返回固定原因/退出 1，保存已观察的有限样本；不会混用新 GPU 数据。Ctrl+C/SIGTERM 保存中断报告并退出 130。Make 非零配方退出通常映射为 2，准确原因以报告 `exit_code` 为准。

这个工具只记录。若模型由现有 `make local-model-start` 启动，停止模型仍由它独立的显存监督器处理；观测器不会代替监督器。退出 0 只说明本次采样，没有承诺每一时刻都满足预算。

## 可选游戏观察

2026-10-10 用户明确主要需求是为 PC 游戏保留显存。至少 6 GiB 的预算与模型监督继续执行；下面的游戏场景观察为可选项，不阻塞功能开发或发布。

1. 游戏已运行后，显式 `make local-gpu-observe DURATION=300 SCENARIO=game` 记录游戏自身场景。
2. 若要同时使用模型，在另一个终端显式 `make local-model-start`；启动时必须通过冷加载预算，不足时保持停止。期间运行 `make local-gpu-observe DURATION=300 SCENARIO=game-model` 并使用已批准的业务请求，确认实际体验与报告。
3. 对比最低剩余、采样峰值和间隔；如监督器停止模型，保留报告及原请求状态，不自动重发。结束后 `make local-model-stop`。

选择观察游戏场景时，需要实际游戏运行及用户确认场景。模型语义质量另见 [RSS 质量基线](rss-value-quality.md)，当前注入/内容不足基线失败，观测不能替代质量验收。

## 阶段三验收

4 类无 GPU 测试覆盖参数上限/重复参数、6144/6656 边界、设备和容量改变、读数缺失、慢查询及中断；共享报告私有权限/不覆盖测试和既有监督器边界测试通过。CI 只运行这些合成测试，不查询 NVIDIA 或调用模型。无 Rust/API/数据库/UI 变更，全仓 Rust、前端与生产镜像/core smoke 沿用本批前两阶段验收；专项浏览器未重跑。

2026-10-04，模型已停止的 unspecified 场景完成 30 秒真实 RTX 5070 Ti 观测：54 个样本、实际 30001 ms、最长间隔 561 ms、最低剩余 13509 MiB（约 13.2 GiB）、采样最高占用 2794 MiB，没有低于 6144/6656 阈值的样本。额外真实 SIGTERM 验证保存部分报告/退出 130。没有启动游戏，本次结果不代表游戏并行峰值；模型仍停止、没有基准锁残留。
