## 首个工具：knowledge_search

开启现有 `KNOWLEDGE_INDEX_ENABLED=true` 后注册，无新增配置或数据库迁移。仅访问当前登录用户已索引的知识片段，复用 PostgreSQL 复核和现有索引/检索并发额度。未启用时工具列表为空。只读不等于免费：查询会调用向量模型，但不索引文档、不生成答案、不写记忆。

- `GET /api/tools`：返回可用工具的名称、说明、参数 schema、只读及费用提示，需要登录。
- `POST /api/tools/knowledge_search`：需要登录和 `X-Requested-With: personal-ai`，请求体为 `{"query":"问题","limit":5}`，成功返回 `{"tool":"knowledge_search","output":{"hits":[…]}}`。
- query 为 1–1000 字符且不能全为空白；limit 为 1–5，默认 5。拒绝额外字段，包括客户端传入的用户/会话 ID。身份取自 Cookie 会话，调用上下文 ID 由服务端生成，不代表持久化对话。
- 成功响应 `Cache-Control: no-store`；标题、来源、分块和得分结构与检索 API 相同。调用方必须把结果视为不可信资料，不可据此执行代码或提升权限。

错误：401 未登录、403 CSRF/权限失败、400 参数无效、404 工具未注册或未启用、429 并发已满、504 超时、502 工具/依赖失败。依赖错误不伪装成空结果，也不返回底层异常正文。管理 Bearer token 不能替代用户会话。

## 执行边界

`crates/tools` 只执行应用预先注册的 `Tool`，拒绝重复名称，无动态插件、shell、文件或 Git 执行。参数 JSON 对象序列化后最多 8 KiB（HTTP 请求体另有 16 KiB 限制），执行器并发最多 2 个，单次等待最多 35 秒，返回内容最多 64 KiB。各工具负责具体参数和数据权限校验；当前唯一注册工具只读。新增工具必须单独评审授权和副作用，不能仅凭名称或说明授予权限。

超时与取消依赖异步协作，不是进程沙箱，不能强制终止阻塞代码或撤销已发送请求；输出限制在返回后检查，工具本身仍需限制内存分配。当前检索分块数有界。不自动重试，调用失败或取消后再次请求可能重复计费。现有日志只记方法、状态和耗时；持久化工具审计、调用预算及模型工具循环未实现。

## 验证

- Rust：白名单、重复注册、参数上限、身份传递、并发、超时/输出上限及容量释放；API 校验会话、CSRF、伪造身份、参数、未启用和错误脱敏。
- `make smoke-index`：真实 PostgreSQL/Qdrant、本地模型夹具；Next.js/Nginx 两个入口验证工具清单、调用结果、来源核对和用户隔离，同时回归原有索引、检索、问答与重启持久化。
- 无新增 UI；真实付费模型、Memory、Scheduler 和 MCP 传输不在本步验收范围。
