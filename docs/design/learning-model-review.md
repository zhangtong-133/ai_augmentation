# 模型核验分享预览与返回协议

本阶段提供离线协议、私有只读预览和页面。没有模型请求、连接授权、派发记录或模型建议持久化，不消耗 API 或订阅额度，不产生自评，也不将人工核验改成模型判断。无需数据库迁移。

## 分享边界

`GET /api/learning/plans/{plan}/tasks/{task}/evidence/model-preview` 要求当前会话，响应（含错误）为 no-store，拒绝未知查询参数。Next 代理仅放行这个精确 GET 路径。服务端在 owner 事务锁内读取已有计划、任务、完成结果和未删除的四项结构化证据；来源自评撤销、技能停用或版本变化、计划删除时拒绝预览。客户端不能提供替代正文。

返回 `protocol_version`、`system_prompt`、`input`。input 只包含技能名称、训练要求、四项证据和摘要；不含原始训练备注、人工核验理由、自评分数、其他技能或来源 ID。摘要绑定当前用户、计划/任务/结果/证据/技能 ID、技能版本、分享正文和系统提示，来源 ID 不直接发送。协议固定为 `learning-model-review-v1`。

不保存预览副本，重复读取相同来源得到相同摘要。未来授权必须冻结实际分享内容和连接/模型版本，并在发送前重新验证来源；本接口不代表授权。

## 严格返回协议

纯函数 `validate_response` 接受由服务端构建的预览和最多 24 KiB 的 JSON 响应。根必须恰好包含协议版本、输入摘要和 explanation/work/verification/limitations 四个维度；每项 verdict 仅 missing/unverified/supported，reason 为 1–500 字，citations 最多两个 `{field,quote}`。

引用必须为对应证据字段的连续原文，1–300 字，不能重复；supported 至少有一条本维度引用。拒绝错版本/摘要、缺项、额外字段、重复 JSON 字段、Markdown 包装、超长内容、伪造引用。协议没有分数或工具动作字段。系统提示将全部材料视作数据，不执行材料内指令或访问链接。

结构和原文引用校验不能证明语义正确；模型结论始终是建议，不能自动变成人工核验、能力分数或执行授权。

## 页面和验收

已有证据下显式点击“预览模型分享材料”后加载完整分享 JSON，并标注“未发送”。可关闭；刷新、修改或删除来源、切换账户、登录失效时清除页面预览。沿用学习面板的请求取消与晚到响应保护，不使用浏览器持久化存储，内容按纯文本展示。

覆盖纯协议拒绝路径、真实 PostgreSQL HTTP 的用户隔离/来源有效性/无写入、Next 和 Nginx 的桌面与移动端预览、关闭、删除、会话失效验收。

后续依次实现：订阅连接与模型绑定、精确分享及单次额度同意；持久化授权/取消和一次性派发；模型返回验证与私有建议展示。每一步保留现有人工核验及显式自评确认边界。

本批验收结果：`make check`、前端 lint/typecheck/build、162 个存储 PostgreSQL 用例、11 个学习 HTTP 用例、完整核心 HTTP smoke 和 26 个学习页面双入口浏览器用例通过。桌面/移动截图已检查，测试栈已清理。本地未重跑其他页面全量、对象存储/向量索引、公网或真实模型验收；CI 时限调整的全量效果由后续 CI 验证。
