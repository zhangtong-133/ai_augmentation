# Sprint 3：MCP 凭据管理与费用授权页面

登录工作台后显示“MCP 宿主授权”，使用已有登录态凭据管理 API，不增加迁移或后端权限。桌面直连 Next.js 与移动端 Nginx 入口保持相同行为。

## 用户流程

1. 填写宿主名称，选择 1、7 或 30 天有效期。
2. 阅读只读知识检索的权限与费用说明，勾选信任宿主及费用授权后创建。修改宿主或期限会清除勾选；不支持自动续期。
3. 创建成功后仅在当前页面临时保留凭据，默认隐藏。用户主动显示后手动保存到客户端秘密环境配置 MCP_ACCESS_TOKEN。页面不自动复制，不写入浏览器存储、URL 或日志。
4. 刷新列表、刷新页面、页面隐藏、离开、退出或主动清除时移除页面持有的明文。隐藏明文按钮只隐藏显示，可在本次交付期间再次展开；清除后无法恢复。没有保存明文时，先撤销再重新签发。
5. 列表显示宿主、只读权限、签发/到期时间和有效/到期/撤销状态；通过刷新更新状态。撤销要求确认，可取消确认。

费用说明明确：向量模型可能计费，尚无精确金额上限；所有宿主和普通工具入口共用每日 100 次额度。客户端仍需逐次取得用户同意。网页退出不会撤销独立凭据，密码重设会撤销全部凭据；撤销不取消已经开始的检索。

## 故障与隔离

创建是非幂等接口。发送后遇到超时、网络故障、服务错误或响应不完整，不自动重试，也不提供“重试创建”按钮。页面锁定新签发，要求先成功刷新列表并核对记录、撤销无法取得明文的凭据，再主动解除锁定、重新填写和确认费用。若刷新或关闭整个页面，无法保留本次内存中的未知状态；重新授权前仍应先查看列表。

撤销使用原凭据 ID，可安全重试。结果未知时保留确认对象，不切换到其他凭据。401 清除明文和列表，禁用授权操作，并提示重新登录。额度错误给出 20 条签发/有效凭据合计限制及撤销不释放当天额度的说明。

请求设置超时、取消信号及当前请求标识；卸载与页面离开使晚到响应失效。组件按用户 ID 挂载，切换账户不会保留明文、列表或未完成的确认。宿主文本由 React 转义，明文默认不进入 DOM；没有自动调用 MCP 工具。

## 验收

Playwright 使用真实创建、列表和撤销 API，覆盖费用确认、改期限重新确认、重复点击、一次性交付、页面离开清除、刷新后不可恢复、真实 Bearer 撤销、宿主文本转义和移动端溢出。故障测试覆盖创建响应丢失不重复签发、撤销丢失响应后按原 ID 重试、401 清理，以及账户切换时晚到创建响应不能泄露旧账户凭据。

两种入口均生成清除明文后的截图；涉及明文的测试关闭自动失败截图和追踪记录。无付费模型调用。使用 make browser-test 执行完整隔离浏览器验收。

已提供 [MCP 凭据运维核对](sprint-3-mcp-operations.md)：只读查询有效、到期和撤销记录，检查授权数量及异常配置，不读取 token、摘要或宿主名称。
