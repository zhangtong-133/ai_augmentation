# Sprint 4：学习管理 HTTP、页面与显式训练结果

在技能仓储之上接入会话 API、Next 同源代理与学习管理页面。新增迁移 `0027_learning_results.sql`。应用装配使用独立 `LearningStore`，不需要新环境变量；没有模型调用、后台执行或通知。

## HTTP 协议

所有路径位于 `/api/learning`，使用当前会话用户，不接受 owner。写入要求 `X-Requested-With: personal-ai`；响应（含错误）设置 `Cache-Control: no-store`，正文上限 16 KiB。独立输入 DTO 拒绝未知字段；不接受客户端计划、摘要或时间。UUID 必须非零，规范化为标准形式。版本和毫秒时间输出十进制字符串，版本输入要求无前导零的非负 i64 范围十进制字符串，避免 JavaScript 精度损失。

| 方法与路径 | 输入 / 行为 |
| --- | --- |
| `GET /snapshot` | 完整有界技能图、自评及快照版本 |
| `PUT /skills/{id}` | `revision`、`name`、`enabled`、`prerequisite_ids`；版本 0 创建，否则 CAS 修改 |
| `DELETE /skills/{id}` | `revision`；墓碑及派生内容清理 |
| `POST /assessments` | `request_id`、`expected_revision`、`skill_id`、`skill_revision`、`score`；显式自评 |
| `GET /plans?after={id}` | 每页 20 条，仅计划元数据，返回 `next_cursor` |
| `POST /plans` | `request_id`、`expected_revision`、`budget_minutes`、`goal_skill_ids`；服务端生成并保存，返回 201 |
| `GET /plans/{id}` | 不可变计划及当前独立 `results` |
| `DELETE /plans/{id}` | 空对象；清除正文和结果，保留计划墓碑 |
| `POST /plans/{plan}/tasks/{task}/result` | `request_id`、`outcome`、`note`、`actual_minutes`；返回原计划及结果 |

NotFound 映射 404、输入错误 400（JSON 提取按 Axum 返回 400/413/415/422）、版本/额度/终结冲突 409、存储不可用 503。错误码不包含 SQL、技能名称或训练记录。Next 代理仅放行上述方法/路径，保留 CSRF 检查；Nginx 使用现有 `/api/` 转发。

## 训练结果与事务

`learning_tasks` 保持计划定义状态（planned / invalidated / deleted）。新增 `learning_results` 使用 `(user_id, task_id)` 主键，保存用户请求 ID、completed/cancelled、备注、实际分钟和数据库记录时间，通过用户/任务复合外键隔离。计划响应将可变的 `results` 放在不可变 `plan` 之外，原摘要不变。

每项训练只能终结一次。完成要求实际分钟 1–180；取消要求 0。备注去除首尾空白，最多 2000 个 Unicode 字符且不超过 8000 字节，允许换行和制表，拒绝其他控制字符。记录数受现有每计划最多 5 项、每用户最多 1000 计划约束。

首次记录在同一用户行锁下复核计划摘要、任务逐项定义和归属。相同任务、请求 UUID、规范化结果参数重试返回原记录，不重复写入或更新时间；不同请求或内容竞争同一任务时至多一方成功，其余 409。同用户尚存结果的请求 UUID 也不能用于其他任务。没有可改写的中间状态，因此不引入结果版本：主键唯一终结和锁提供并发控制。

结果不递增学习快照版本、不写自评、不解锁技能、不再规划。技能或自评后来修改时，旧计划仍可记录历史练习，页面明确展示快照语义。完成自评准备任务也不会自动保存分数；用户需单独提交显式自评。

技能删除使整份来源计划失效。新增任务状态触发器在 invalidated/deleted 时删除对应结果行，接入现有技能与计划删除事务；失败回滚同时恢复计划、任务和结果。账户删除级联清理结果。墓碑任务不能再写结果，原请求重试不能恢复删除内容。结果行清除后不保留备注或其摘要；旧请求 UUID 不再占用独立结果唯一索引，但旧计划/任务仍拒绝写入。

## 页面行为

学习管理按账户 ID 挂载。用户可添加/修改名称、启用状态和最多 8 个先修关系，选择技能提交 0–100 自评分数，选择最多 10 个目标和 5–180 分钟预算生成计划。界面展示当前版本的最新自评，修改技能后旧评分不再显示为当前能力。删除前置技能后保留依赖阻塞；编辑依赖时可显式移除该引用。

计划详情展示生成时的技能评估、阻塞原因、时间预算及任务。每个任务可填写记录，确认完成或取消；单独说明结果不可修改、自评不会自动改变。历史有前后翻页和显式状态刷新，删除技能或计划需确认。用户内容仅作为 React 文本呈现。

所有操作串行执行。写入前在组件内存保存精确路径、原请求 UUID、版本和正文；网络失败后可核对保存状态或重试原操作，不自动生成新 UUID。查询不保证此前写入成功，提示用户核对实际保存内容；404 保留恢复提示。刷新重置编辑表单和旧详情，409 提示版本、额度或终结冲突。401 清空技能、自评、表单、计划、结果和待恢复操作并禁用继续操作；卸载中止请求且晚到响应不能更新新账户。
