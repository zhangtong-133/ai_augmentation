# 私有核验状态观察页面

在授权详情和历史详情中，用户可对 `authorized` 或 `running` 请求显式点击“观察执行状态”。观察只发起一次现有[状态事件 GET](learning-status-events.md)，不批准授权、不领取执行、不调用模型。停止观察仅中断读取，不取消本机已经开始的执行；取消授权仍使用独立明确按钮。

## 页面生命周期

观察开始即收起旧分享材料及建议，显示通过校验的最新状态。只有终态或观察超时正常结束后，才查询原授权一次，由原 JSON 接口返回仍然有效的最终建议。事件正文不会作为建议渲染，也不用于填写或提交能力分数。若查询失败，旧材料保持收起，可手动核对原授权。

断线、错误内容类型、截断、协议不匹配、非法序号及连接限额只显示固定提示；不回显原始事件/服务错误，不自动重连或发送模型请求。用户可手动重新观察仍可执行的请求。终态已观察到但正文传输未正常结束时，不自动读取最终建议。

停止、查询、取消、切换授权/计划、刷新、组件卸载和账户切换都会中止当前观察。每次读取绑定自己的 AbortController，旧响应不能进入新的观察或账户。开始观察时保留原授权 ID；停止不会创建新请求。普通页面操作仍可使用，不会被二十秒观察占住操作锁。

初次事件请求返回 401，或者有效 `closed/session_unavailable` 事件到达时，立即调用学习面板统一会话失效处理：中断并清空当前学习请求、计划、证据、历史、技能及进度，提示重新登录。无需等待另一条 GET 失败才清理。其它关闭原因收起材料并保留手动核对入口。

## 接收限制

使用可取消的 fetch，不使用自动重连的 EventSource。客户端最长 25 秒（服务端最长 20 秒）；单帧最多 2048 字符、整个事件流最多 32 KiB UTF-8。文本严格按 UTF-8 解码，支持任意网络拆包，消费当前后端生成的 LF 分帧格式。只接受 `learning-status-v1` 和当前请求 ID，SSE ID/JSON sequence 必须一致且从零连续递增。

事件字段、状态枚举、终态标志和关闭原因均显式验证；拒绝未知字段、重复/跳号、终态后事件和非完整 EOF。心跳计入大小限制但不推进序号。读取结束或异常时取消 reader 并释放锁；不保存本地存储或跨页面缓存。

## 验收与后续

`npm --prefix apps/web test` 通过现有 TypeScript 编译器在内存中加载真实读取器，验证拆帧、UTF-8、身份/序号、字段注入、截断、容量、取消与不重连；无需新增依赖，并在 CI web job 执行。`make learning-acceptance` 包含状态流真实双代理验收，以及 `learning-events.mjs` 的八类双入口页面用例，生成观察中截图。

本批不增加原始模型文本的跨进程桥接。后续顺序为：临时正文通道与持续订阅/来源复核 → 临时内容页面及严格最终建议分离 → 独立本地模型适配 → 部署恢复与真实用户质量验收。真实订阅可用性和质量仍单独验证。
