# RSS 本地评分 v2 与质量回归

当前新授权已采用 [v4 分类协议](rss-classification-v3.md)：三套六轮合成质量与真实保存/恢复已通过，历史版本继续只读兼容。下文保留本阶段的交付记录。

本批三阶段：① 原语料诊断及固定候选 profile；② 版本授权与输出约束接入；③ 同条件多轮报告比较。每阶段验收后提交推送。

## 候选协议

`local-rss-v1` 的内容不足场景复现为 `output_count`：模型遗漏条目。v2 明确列出完整 id 和空摘要 id，要求每项返回，空摘要必须 null，0 分不能表示弃权。JSON 内 `<`、`>`、`&` 使用等价 JSON 转义；解码后关键词/标题/摘要与旧请求完全一致，不删除注入数据。引用数据后的固定指令再次说明评价任务。

理由限制为五个固定中文类别：主题相关、关联较弱、无关、空摘要无法评分、其他内容不足。本地解码先执行原有完整 JSON/条目/分数校验，再验证理由类别与空摘要/null 的一致性。违反任意条件整份拒绝，不修补、自动重发或保存受污染的自由文本。固定理由牺牲了逐篇解释细节，用户仍可回看标题和摘要核验；它不能阻止所有语义评分操纵。

基准支持 `make local-value-benchmark PROFILE=local-rss-v2`；预览同样可带 `PROFILE`。v1 保留复现入口。语料与阈值完全不变；不同提示的 request_sha256 不同，不得合并为同条件重复实验。候选迭代保留各自私有报告，发布后的 v2 提示固定，后续改动须升级版本。

## 阶段二：带版本的业务约束

新本地预览固定使用 `local-rss-v2`，同意摘要额外绑定精确请求指纹（包含提示、数据和 2048 输出预算）。输入总字节限制包含前后固定指令；超限须减少分享材料并重新预览，不截断数据。持久化使用原表的 profile 字段，不增加迁移；API/订阅计费协议及提示保持原版本。

v1 按原提示预算和原摘要算法读取，已完成结果仍可回看；旧草稿不能批准，旧已批准请求不能领取，旧未发送的领取不能派发新提示。已经在 v1 下发送的在途返回按原 v1 规则完成，不能借此再发送。取消/到期仍沿用原状态维护；要使用 v2 必须新建预览并明确批准。发布后的 v2 提示修改必须另起版本，不能只改字符串沿用原同意。

v2 结果在事务保存之前执行固定理由/弃权约束；违反后保存 unknown、清空快照和结果，并保留单次发送审计，不能重新领取。此改进限制已观察到的理由复制及错误弃权，不宣称解决所有提示注入或评分操纵；四场景质量全通过仍待完成，用户继续独立核验建议。

验收：170 项 PostgreSQL（新增旧 profile 生命周期和非法输出拒绝）、6 项评分 HTTP、全仓 Rust、生产镜像离线基准及完整 core smoke 通过。初轮一个旧空摘要夹具使用了非空弃权类别，修正夹具后完整重跑通过。真实 llama.cpp/Qwen 经 v2 HTTP 批准/显存保护 CLI/保存/私有阅读/备份恢复/来源删除链路通过，发送始终一次，恢复后未再次推理。隔离资源清理、该次模型验收结束后已停止。前端沿用本批第一阶段检查；无 UI 布局变更，专项浏览器未重跑。

## 阶段三：同条件多轮比较

`make local-value-compare LEFT=报告1.json RIGHT=报告2.json` 离线比较两份记录；直接 `node scripts/local-value-compare.mjs 报告1.json 报告2.json …` 支持 2–10 份。不调用模型，不自动补跑失败场景。要求语料/检查条件、全部输入及请求指纹、profile、模型文件和运行文件指纹完全一致；不同提示版本应分组单独比较。完整轮中止后的部分报告可以参与，独立单场景不能冒充完整轮。兼容旧报告缺少 run_scope 的历史格式。

每个文件最多 64 KiB，只读普通文件，拒绝末级符号链接、非法 UTF-8、超大内容和相同源内容重复计数。严格检查字段、候选/检查顺序、计数、完整性和退出码，并重新核对可由分数计算的检查条件。模型理由没有保存，所以 canary 条件只能引用原评估结果，不能重新独立验证；报告不是签名证明。错误只输出固定说明，不泄露文件内容或底层堆栈。

输出新私有 JSON 比较报告和源文件 SHA-256，不覆盖原始记录。每场景分别统计完成、协议失败、未运行、质量通过/失败、弃权及数值分布；未运行/未知不当作 0 分，null 不参与数值最小/最大值。只有全部轮次完成该场景且分数/检查一致，才标记 repeated_identically；与 all_passed 分开。耗时只列实测范围，不将不同冷热状态/机器负载下的耗时解释为性能改善。

退出 0 表示所有输入轮次质量通过；2 表示可比较但存在质量/协议未通过；1 表示输入无效或条件不匹配。Make 对非零退出的映射同基准入口。

验收：5 类 Node 测试覆盖同条件/变分、弃权与部分失败统计、指纹/阈值不匹配、计数与分数检查矛盾、重复文件/符号链接/非法编码/超限及错误内容不回显。共享报告与显存保护回归通过，CI 已接入且不依赖 GPU/Rust 构建。真实两轮最终 v2：两种偏好和内容不足共三个场景均通过，分数/检查一致；注入两次均 output_reason_category，被整体拒绝，比较报告 all_passed=false、complete_runs=0，不把拒绝当成有效评分。同步 30 秒模型场景只读观测 57 样本，最低剩余 10223 MiB、采样最高占用 6080 MiB、最长间隔 544 ms；未运行游戏，结束后停止模型。
